Settings

This version is built to look like a wall-mounted family command center. Weather loads automatically from Open-Meteo using your saved latitude and longitude. Calendar events can load from multiple Google Calendar IDs after you add a Google API key.

Family Photos

Google Photos does not work like a simple public calendar embed. The practical setup is either: use image URLs from a shared album export, place family photos in a local folder beside this file, or later connect the Google Photos API.
